Portfolio System

Build, document, upload, repeat.

Every computer science session should create evidence of learning. The goal is not only to finish courses, but to build a visible portfolio that looks strong to universities, internship recruiters, and future collaborators.

  • Plan what was learned.
  • Create one small folder or mini project.
  • Write a simple README.
  • Push to GitHub.
  • Add the best work to the personal website.
